# Faculty photos

Save one photo per faculty member here, named by last name:

  Aloysius.jpg   Dai.jpg   Krishnaswamy.jpg   Somavat.jpg   Wan.jpg   Yang.jpg

Capital or lowercase names both work, and .jpg, .jpeg, .png, or .webp are all fine.
Portrait (taller than wide) photos work best; the site crops them into a circle.

To use a different file name for someone, add this to their entry in data/faculty.js:
  image:"images/your-file-name.jpg",

If no photo is found, the site shows the person's initials.
